Осы Android build логын толық талда.

Тапсырма:

1. Нақты ERROR жолын тап.
2. WARNING жолдарын бөлек көрсет.
3. Build не себепті құлағанын анықта.
4. Қай файлда мәселе бар екенін көрсет.
5. Қандай кодты өзгерту керек екенін жаз.
6. Толық түзетілген кодты бер.

Қазіргі лог бойынша байқалғандар:

- Gradle 8.0 жүктелді.
- Android SDK орнатылды.
- NDK 25.2.9519653 табылды.
- CMake 3.10.2 қолданылып тұр.
- configureCMakeDebug[arm64-v8a] кезеңіне дейін жетеді.
- Көп рет қайталанатын ескерту:

WARNING:
An old version of CMake is being used that cannot automatically detect compiler attributes.
Update to CMake 3.19 or newer.

Мүмкін себептер:

- CMake 3.10.2 ескірген.
- CMakeLists.txt файлында қате болуы мүмкін.
- app/build.gradle ішінде CMake нұсқасы сәйкес келмейді.
- Native C++ кодында қате болуы мүмкін.

Логты талдап, нақты қай жерден құлап тұрғанын анықта және түзетілген кодты бер.
